# Taghreed Said — Portfolio

Personal portfolio of **Taghreed Said**, UI/UX Designer & Computer Engineer.
Built with React 19, Vite, Tailwind CSS v4 and Motion. English / Arabic (RTL) and dark / light themes.

## Run locally
```bash
npm install
npm run dev
```

## Edit content
- Text (EN/AR), contact info: `src/data/content.js`
- GitHub & Behance project cards: `src/data/projects.js`
  - Add a screenshot to `public/projects/` and set `image: 'projects/name.webp'` to replace the drawn cover.

## Deploy
Import this repo on [vercel.com](https://vercel.com/new). Framework preset: **Vite**. No extra settings needed.
